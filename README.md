# Auto Music

把 MIDI 谱面映射到口琴键位，在桌面版直接自动演奏，或导出按键脚本。

## 自动演奏

桌面版载入 MIDI、选好声轨后，点击「自动演奏 → 开始」。程序等待 5 秒，期间切换到目标窗口，然后发送音键和左/右/中鼠标按钮事件。**普通鼠标即可，不依赖罗技硬件或 G HUB。** Windows 默认选虚拟 HID；界面会显示驱动状态，并可安装完整的已签名驱动包。当前仓库没有签名驱动包，详见 [Windows 驱动说明](windows-vhid/README.md)；也可在界面切换为系统模拟输入。按全局 `F8`（若未被其他程序占用）或回到程序点击「停止」，会停止播放并释放程序按住的输入。高速播放会优先满足按键最短时长与修饰键提前量，实际曲长可能因此增加。

macOS 首次使用需要在「系统设置 → 隐私与安全 → 辅助功能」允许本程序控制电脑。浏览器版无法发送系统输入，自动演奏按钮不可用。

Windows 发布版右上角有「检查更新」按钮：会检查 GitHub Release、下载并验签安装新版。构建与签名密钥配置见 [Windows 构建与更新发布](.github-workflow-notes.md)。

Windows 虚拟 HID 是软件设备，不会在 USB 总线上出现物理 USB 信号。本仓库当前在 macOS 环境开发，Windows 驱动尚未实机编译或加载验证。

引导练习窗右上角可关闭；练习时按音键和相应鼠标修饰键，按键时间误差不超过 70 毫秒记 Perfect（+100），不超过 160 毫秒记 Great（+50），错误键、错误修饰或逾期记 Miss（−50）。Windows 桌面版会在引导窗打开时读取全局按键状态；其他平台只在引导窗获得焦点时计分。自动演奏期间不计玩家按键分数。

目标程序是否接收系统模拟输入取决于它的输入方式与规则；本功能不能保证绕过检测。

## 模拟演奏

演奏参数中可选「轻微」或「自然」：在音键按下、抬起时加入小幅随机延迟，较长休止处回收累计偏移。每次自动演奏或导出重新生成，CSV 和 G HUB 脚本均可用。默认关闭，试听仍按原始谱面播放。

这只能让输入的时间间隔产生变化，**不能保证避开反作弊或宏检测**。使用前请遵守目标程序的规则。

## 不做什么

- **不保证反作弊规避。** 时间扰动的效果可以测量，但无法由此证明能避开检测。

## 键位规则

游戏口琴是单音乐器。键盘上 `Z X C V B N M` 是 do..si，逗号补最高音；
升降号与八度靠鼠标修饰键：

| 鼠标 | 作用 |
| --- | --- |
| 不按 | 基准八度 |
| 左键 | 降一个八度 |
| 右键 | 升一个八度 |
| 中键 | 升半音 |

可演奏范围是基准 ±1 个八度，外加上方高八度的 do / #do。

## 时序模型（为什么不会漏音）

目标程序**按帧采样键盘**（60fps ≈ 16.7ms 一帧）。
如果「松开前音 + 八度键 + 中键 + 按下本音」全挤在一帧以内，
游戏会把整簇折进同一帧，排在末尾的音键直接被吃掉 —— 听感上就是漏音。

所以所有最小间隔都按**物理毫秒**给，而且**不随播放速度缩放**：

- 修饰键比音键早至少一帧
- 每个音至少按住一帧多一点（`帧 + 1ms` —— 只给整一帧时，
  按下若正好落在帧边界上，整个按住区间可能一个帧点都不含）
- 同键重触发至少隔一个间隔
- 音符重叠时用**槽位顺延**，不靠缩短前音腾位置
  （否则产生零时长按键，游戏一帧都读不到）

三档预设：稳健（30fps）/ 标准（60fps）/ 极限（高帧率）。

界面底部实时显示诊断：修饰不足 / 重触发过密 / 按持不足，三项都应为 0。

## 运行方式

**桌面程序**（可直接自动演奏，也能自己选导出目录）：

```bash
npm install
npm run desktop          # 开发模式，起窗口
npm run desktop:build    # 打包成安装包
```

**浏览器**（开发调试快）：

```bash
npm run dev              # http://localhost:5273
```

**测试**：

```bash
npm test                 # Vitest
```

### 打包到 Windows

mac 上没法交叉编译 —— Tauri 依赖目标系统的 WebView2 与链接器。
仓库已包含 [GitHub Actions 工作流](.github/workflows/windows.yml)：推送 `main` 生成测试用 exe，推送 `vX.Y.Z` 标签生成 Release 和应用更新包。首次使用的签名密钥与仓库配置见 [发布说明](.github-workflow-notes.md)。

### 目录

```text
src/
├── core/
│   ├── mapping.ts          # 音高 → 键位/八度/半音
│   ├── schedule.ts         # 调度算法（核心）+ 诊断
│   ├── midi.ts             # MIDI 解析
│   ├── export.ts           # G HUB Lua / CSV 导出
│   ├── save.ts             # 落盘（桌面壳走系统对话框，浏览器走下载）
│   ├── library.ts          # 内置曲目库
│   └── *.test.ts           # 核心逻辑测试
├── components/PianoRoll.tsx # 卷帘
├── styles/app.css
└── App.tsx

src-tauri/                   # 桌面壳（Rust + Tauri 2）
public/midi/                 # 内置曲目库（26 首，公共领域）
```

### 内置曲目

`public/midi/` 下 26 首，全部来自 [Mutopia Project](https://www.mutopiaproject.org/)（公共领域）：
Bach、Chopin、Mozart、Brahms、Satie、Pachelbel，加上 4 首口琴示例。

**不放流行歌曲。** 现代流行乐词曲版权在保护期内（中国：作者终生 +50 年），
把 MIDI 文件提交进仓库等于分发受版权保护的作品，会随 git 历史一直存在。
自己的曲子用「打开 MIDI 文件…」导入即可 —— 文件留在你机器上。
